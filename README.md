# Erin's Kitchen

A recipe site for Erin: dishes from her food Instagram plus new ideas, built to follow on a phone.

Live at https://airpengwn.github.io/erinskitchen/

Recipes live one per file in `library/recipes/`, and each person's page reads from `people/<name>.json`. To turn on "Add a recipe" (paste text or a screenshot and Claude formats it), see [SETUP.md](SETUP.md).
